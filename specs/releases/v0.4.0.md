# Figure Composer 0.4.0 — Milestone 8

Status: Implemented checkpoint `0.4.0-m8`  
Date: 2026-09-17

## Scope

Milestone 8 exposes the existing ordered A4 page architecture without turning the application into a general document editor. Page order remains canonical, active page remains viewport state, and all geometry remains page-local millimeters.

## Delivered

- Compact previous/next navigation, page count, and Add Page.
- Empty and confirmed populated-page deletion while keeping at least one page.
- Page duplication with new stable page/panel IDs.
- Earlier/later page ordering with stable ownership IDs.
- Explicit selection movement to any page or adjacent page.
- Safe-area clamping, top placement, preserved group-relative geometry, and no silent scaling.
- Auto Pagination state retained and visible.
- One Undo/Redo transaction for every page command.

## Verification

- `npm test`: 12 files, 144 tests passed.
- `npm run build`: TypeScript and Vite production build passed.

## Known limitations

- Direct cross-page drag and page thumbnails are not included.
- Destination collision avoidance is manual.
- Oversized groups are rejected rather than resized.
