# Figure Composer v1.0.1 Release Record

Release date: 2026-09-18  
Semantic version: `1.0.1`  
Visible version: `v1.0.1`  
Project schema: `0.1.0`

## Scope

This patch release adds a versioned Windows launcher and closer for the repository's managed local preview while native Tauri packaging remains unavailable on the current host.

## Changes

- Added `Figure Composer Launcher v1.0.1.cmd` for minimized startup and default-browser opening.
- Added `Close Figure Composer v1.0.1.cmd` for ownership-scoped shutdown.
- Added a random per-launch Windows named pipe and token; the closer never enumerates or terminates unrelated Node processes.
- Added `npm run launcher:generate` and expanded version consistency enforcement and tests.
- Synchronized the web title/label, Tauri title, npm package, Cargo crate, and release records at `1.0.1` / `v1.0.1`.

## Verification contract

- Run `npm run version:check`, `npm test`, `npm run build`, and `npm audit`.
- Start the preview with the launcher logic, verify `http://127.0.0.1:5173/`, then close it with the matching closer and verify the owned listener/runtime metadata are gone.
- Native `.exe` / `.app` installation remains a separate release-host gate.

## Rollback

Restore Git tag `v1.0.1`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. Restore tag `v1.0.0` to return to the prior release. No `.figproj` migration is required.

## Known limitations

- The preview pair requires Node.js and serves the existing development build locally.
- It is not the final standalone Windows or macOS package.
- Windows installer and macOS application certification remain pending native toolchains.
