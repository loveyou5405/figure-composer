# Figure Composer v1.1.1 Release Record

Release date: 2026-09-20
Semantic version: `1.1.1`
Visible version: `v1.1.1`
Project schema: `0.1.0`

## Scope

This bug-fix checkpoint corrects Auto Layout alignment for panels without labels and synchronizes Figure Composer scale percentages with the reference size PowerPoint reports for generated images.

## Changes

- Rows align panel image centers rather than mixing unlabeled image tops with visible-label footprint tops.
- Visible label bounds remain part of row height and collision avoidance.
- Imported and replaced sources use their intrinsic pixel dimensions at the PowerPoint/DrawingML 96 DPI reference as the stable 100% size.
- Clipboard panels retain their requested physical size while reporting the matching PowerPoint scale percentage.
- Legacy project panel bases normalize during loading without changing saved geometry, coordinates, labels, or source metadata.
- The inspector identifies the field explicitly as `PPT scale`.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test -- --run`, `npm run build`, and `npm audit`.
- Verify a labeled and unlabeled panel in one Auto Layout row share the same image center line.
- Verify a 384 × 192 px image at 60% is 60.96 × 30.48 mm and is exported at that exact geometry.

## Rollback

Restore Git tag `v1.1.0`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. The project schema remains `0.1.0`.
