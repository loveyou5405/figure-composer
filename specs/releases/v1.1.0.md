# Figure Composer v1.1.0 Release Record

Release date: 2026-09-20
Semantic version: `1.1.0`
Visible version: `v1.1`
Project schema: `0.1.0`

## Scope

This checkpoint consolidates the current TIFF, per-page safe-margin, and label-position work, implements the browser/WebView portion of PowerPoint clipboard paste, and records the remaining native source-fidelity workflow in the roadmap and owning module specifications.

## Changes

- Added `specs/modules/13-clipboard-import.md` with provider, fidelity, physical-size, placement, canonical/preview, quality, persistence, export, TEMP, security, test, and manual-verification requirements.
- Connected clipboard contracts to the master specification and the project model, asset import, UI shell, save/load, PPTX export, validation, and desktop packaging modules.
- Documented that browser mode cannot claim Office-native fidelity and that the future Windows Tauri provider must enumerate SVG/EMF/WMF/TIFF/PNG/DIB/JPEG representations.
- Implemented web Ctrl/Cmd+V paste for exposed SVG/TIFF/PNG/JPEG representations with active-page ownership, Other typing, one-entry Undo/Redo, reliable physical-size parsing, 3 mm safe-region cascade, and source-quality/effective-DPI display.
- Added persistent clipboard source diagnostics with a compact collapsed inspector, exact advertised-format recording, canonical-versus-preview reporting, strict vector/lossless/lossy/fallback classification, and effective DPI derived from current displayed size.
- Synchronized npm, Cargo, Tauri, visible web/desktop identity, README, changelog, history, and generated Windows preview controls at semantic version `1.1.0` / visible version `v1.1`.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test -- --run`, `npm run build`, and `npm audit`.
- Verify the generated launcher and closer contain semantic version `1.1.0` and that no stale versioned preview controls remain.
- Native `.exe` / `.app` installation and the PowerPoint clipboard matrix remain separate release-host gates.

## Rollback

Restore Git tag `v1.0.1`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. No `.figproj` migration is required because schema `0.1.0` is unchanged.

## Known limitations

- Browsers and the current WebView can paste only formats exposed to web clipboard events; PowerPoint may provide a raster fallback instead of its EMF/WMF source.
- Native EMF/WMF enumeration, pathless clipboard asset embedding, clipboard preview TEMP generation, and canonical native clipboard-source PPTX export remain roadmap items.
- The managed Windows preview controls still require Node.js and are not the final standalone Tauri package.
