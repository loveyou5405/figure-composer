# Figure Composer 0.3.0 — Milestone 7

Status: Implemented checkpoint `0.3.0-m7`  
Date: 2026-09-17

## Scope

Milestone 7 makes the local scientific figure workflow recoverable and reversible. It adds schema-versioned `.figproj` files, browser Save/Open, missing-source preservation, debounced recovery, dirty state, and atomic Undo/Redo without changing original scientific image files.

## Delivered

- `.figproj` JSON schema `0.1.0` with explicit migration runner.
- Exact multi-page A4 ownership and page-local millimeter geometry round-trip.
- Persistence of labels, types, presets, overrides, asset metadata, and Auto Layout preferences.
- File System Access API Save/Save As plus download fallback.
- Missing-source placeholders after reopen, preserving every panel.
- 750 ms local recovery and Restore / Discard startup choice.
- 200-entry immutable history with redo divergence behavior.
- One history entry per import, delete, drag, resize, layout command, preset/type/label edit, and Auto Layout transaction.
- Compact file/history UI and standard keyboard shortcuts.

## Verification

- `npm test`: 11 files, 133 tests passed.
- `npm run build`: TypeScript and Vite production build passed.

## Known limitations

- Browser download fallback cannot overwrite an earlier download.
- Source bytes are not embedded; reopened assets require Milestone 9 relinking unless a matching source remains live in the session.
- Milestone 8 will expose page navigation and lifecycle operations.
