# Figure Composer 0.2.0

Release focus: Smart Auto Layout + Auto Pagination  
Checkpoint: `0.2.0-m6`  
Date: 2026-09-17

## Delivered

- Balanced, Compact, and Equal Rows deterministic layout modes.
- Geometry-aware contiguous row packing for mixed scientific panel sizes.
- Exact millimeter gaps inside the 12 mm A4 safe area.
- Selection, active-page, and whole-project arrangement scopes.
- Stable multi-page overflow with existing-page reuse and ordered panel migration.
- Default preservation of panel size, type, preset, identity, manual overrides, and labels.
- Optional explicit minor scaling bounded to 95–100% and marked on affected panels.
- Atomic Auto Layout result metadata ready for Milestone 7 Undo/Redo.

## Verification

- Pure layout, scoring, scope, pagination, and metadata tests.
- Production TypeScript/Vite build.
- Browser verification with mixed WB, IF, Graph, and IHC assets.

## Deferred

- Project persistence, autosave, crash recovery, and Undo/Redo (Milestone 7).
- Compact page navigation and explicit page management (Milestone 8).
- Source refresh/relinking, editable PPTX export, review, and desktop packaging.
