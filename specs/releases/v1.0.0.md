# Figure Composer v1.0 — 1.0.0

Status: Source release complete; native host certification pending  
Date: 2026-09-18  
Project schema: `0.1.0`

This release completes Milestones 1-12 and visibly identifies both web and desktop surfaces as `v1.0`.

## Included

- Multi-page A4 scientific figure composition with millimeter-native geometry.
- PNG/JPEG/SVG/TIFF import, panel presets/types, deterministic layout, publication labels, persistence/history, source lifecycle, Review, and editable multi-slide PPTX export.
- Tauri-bundled production frontend with native user-selected file I/O and no production development server.
- Dirty-close Save/Discard/Cancel protection and active-export shutdown gating.
- Per-instance locked session TEMP, conservative stale cleanup, normal-exit cleanup, and distinct persistent recovery/settings storage.
- Build-enforced npm/Cargo/Tauri version consistency and visible `v1.0` identity.

## Rollback

Restore the `v1.0.0` source tag or matching archived source snapshot, install from the committed lockfile, then run `npm run version:check`, `npm test`, and `npm run build`. Do not downgrade a newer project schema without its documented migration; this release uses schema `0.1.0`.

## Pending native certification

The current host cannot produce the Windows executable because Rust/Cargo and MSVC are absent, and cannot produce a macOS `.app`. Double-click launch, full-process shutdown, TEMP deletion, forced-crash recovery, OS drag/drop, signing/notarization, and native PowerPoint checks remain the platform release checklist.
