# Figure Composer v1.3 Release Record

Release date: 2026-09-22
Semantic version: `1.3.0`
Visible version: `v1.3`
Project schema: `0.1.0`
Portable container: `1.0.0`

## Scope

This feature checkpoint makes Figure Composer projects fully portable: one `.figproj` carries all editable document state and every exact source image needed to reopen and continue editing on another computer.

## Changes

- Save and Save As create a ZIP-compatible `.figproj` containing `project.json` and `assets/`.
- PNG, JPEG, SVG, and TIFF source files are embedded byte-for-byte without image transcoding, resizing, rasterization, or lossy recompression.
- Every embedded asset records its original name, MIME/kind, byte size, last-modified time, internal path, and SHA-256.
- Import Figure verifies CRC, manifest ownership, byte size, SHA-256, decoded type, and intrinsic dimensions before replacing the active project.
- Extracted images become live source bindings, so later edits, Save, source checks, and export no longer rely on the original filesystem path.
- Portable Save fails clearly when an exact source is unavailable; preview derivatives are never substituted.
- Legacy JSON `.figproj` files remain readable and can be converted by relinking any missing sources and saving again.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test -- --run`, `npm run build`, and `npm audit`.
- Verify byte-for-byte equality between an imported source and its `assets/` entry.
- Verify a portable project reopens with editable panels and can be saved again after the original external files are removed.
- Verify a modified embedded asset is rejected by SHA-256 validation.
- Verify legacy JSON `.figproj` loading remains available.

## Rollback

Restore Git tag `v1.2.0`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. Portable container v1.0.0 requires Figure Composer v1.3 or newer; project JSON schema remains `0.1.0`.
