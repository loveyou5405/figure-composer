# Figure Composer v1.1.2 Release Record

Release date: 2026-09-21
Semantic version: `1.1.2`
Visible version: `v1.1.2`
Project schema: `0.1.0`

## Scope

This bug-fix checkpoint aligns labeled panels by their label positions and prevents Auto Label from reversing left-to-right order after a panel label is hidden.

## Changes

- Visible non-empty labels in one Auto Layout row share one label-anchor Y position, including manually adjusted label offsets.
- A panel without a rendered label keeps its image center aligned with the preceding image in the row.
- Auto Label recognizes rows aligned by image top, image center, or label anchor, then assigns labels left to right.
- Hidden labels remain excluded from sequencing and consume no alphabetic slot.
- The v1.1.2 closer can authenticate and stop an older managed preview from this checkout after an in-place update without scanning for unrelated Node processes.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test -- --run`, `npm run build`, and `npm audit`.
- Verify differently sized labeled panels in one Auto Layout row have matching label-anchor Y positions.
- Verify a hidden-label panel shares the preceding image center and that the following visible panels retain left-to-right alphabetic order.

## Rollback

Restore Git tag `v1.1.1`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. The project schema remains `0.1.0`.
