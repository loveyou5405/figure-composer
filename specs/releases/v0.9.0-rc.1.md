# Figure Composer 0.9.0-rc.1 — Desktop Release Candidate

Status: Source complete; platform certification pending  
Date: 2026-09-17

Milestone 12 adds a Tauri 2 Windows/macOS shell, least-privilege dialog/filesystem capability, native project/asset/source/PPTX dialogs, persistent desktop source references and rehydration, full standard shortcuts, a compact onboarding path, and a bundled three-page vector demo. Automated gates cover 181 tests, production build, 40-panel deterministic review, generated three-slide PPTX package validation, and a zero-finding dependency audit.

The current host lacks Rust/Cargo, macOS, and native PowerPoint. Installer creation, platform install/drag-drop/crash checks, signing/notarization, and native PowerPoint rendering therefore remain the exact release-candidate certification boundary before `1.0.0`.
