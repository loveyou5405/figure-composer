# Figure Composer 0.5.0 — Milestone 9

Status: Implemented checkpoint `0.5.0-m9`  
Date: 2026-09-17

## Outcome

Milestone 9 adds an explicit, non-destructive scientific source lifecycle without changing the multi-page document model or starting PPTX export.

## Included

- Panel-specific Replace Source with stable panel/page/type/preset/label metadata.
- Default preserve-width/preserve-center sizing with deterministic height recalculation.
- Optional Reapply panel preset sizing.
- Shared-asset Refresh Source and one-transaction Refresh Changed.
- Missing-source Relink that preserves exact panel geometry.
- Filename/byte-size/modified-time source fingerprints.
- Capability-aware Check Sources results: changed, missing, unchanged, or unavailable.
- Explicit-only refresh policy; no silent source replacement.
- SVG object-URL preview preservation and existing local TIFF decoding.
- Undo/Redo and recovery integration.
- ADR-006 documenting browser snapshot and refreshable-binding boundaries.

## Verification

- `npm test`: 13 files, 155 tests passed.
- `npm run build`: TypeScript and production Vite build passed.
- Browser workflow: Replace, sizing decision, preview update, Undo/Redo, Check Sources summary, missing Relink, and console cleanliness.

## Known limitations

- Standard browser input/drop files are immutable snapshots and cannot detect later disk changes automatically.
- Explicit file reselection remains available for Refresh.
- Persistent filesystem handles and folder relinking are deferred to desktop packaging.
- TIFF preview uses the first page and a session-local PNG representation.
