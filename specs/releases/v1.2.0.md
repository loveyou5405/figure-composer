# Figure Composer v1.2 Release Record

Release date: 2026-09-22
Semantic version: `1.2.0`
Visible version: `v1.2`
Project schema: `0.1.0`

## Scope

This feature checkpoint adds explicit multi-page Figure groups, Figure-local automatic label sequences and navigation, and one-deck export of every Figure.

## Changes

- Add Page continues the active Figure; New Figure creates a new first page and restarts automatic labels at A.
- A Figure selector jumps directly to each Figure's first page.
- A status line below the canvas shows the active Figure and local page number without becoming page or export content.
- Auto Layout keeps panels and overflow pages inside their owning Figure; page reordering cannot cross a Figure boundary.
- `All Figures` export writes every Figure/page into one PowerPoint in project order, one A4 slide per canvas page.
- Legacy `.figproj` documents without Figure IDs load as one continuous Figure without changing schema `0.1.0`.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test -- --run`, `npm run build`, and `npm audit`.
- Verify Add Page continues labels on the next page and New Figure restarts at A.
- Verify the Figure selector jumps to the correct first page and the below-canvas caption is absent from PPTX slide XML.
- Verify All Figures produces one deck containing every ordered page as one A4 slide.

## Rollback

Restore Git tag `v1.1.2`, reinstall exact dependencies from `package-lock.json`, and rerun the verification contract. The project schema remains `0.1.0`.
