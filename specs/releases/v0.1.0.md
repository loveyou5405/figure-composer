# Release v0.1.0

## Goal

Deliver the first complete local MVP workflow: import scientific panels, arrange them deterministically across independently modeled A4 pages, label and review the layout, save the project, and export one editable A4 PowerPoint slide per page.

## Included modules

- Project Model
- Canvas Preview
- Asset Import
- Panel Presets
- Layout Engine
- Panel Labels
- UI Shell
- PPTX Export
- Project Save and Load
- Validation

Smart Features contributes deterministic filename classification and scale-consistency guidance only.

## User-visible changes

1. Project skeleton and A4 preview.
2. Image import, drag, and resize.
3. Panel types and WB/IF presets.
4. Snap, alignment, and distribution.
5. Automatic and editable panel labels.
6. Later workflow milestones continue in the post-Milestone 5 roadmap, beginning with Smart Auto Layout in 0.2.0.

## Schema changes

The initial human-readable `.figproj` JSON schema will be introduced in Milestone 7 with schema version `0.1.0`.

## Migration requirements

No migration is required before the initial project schema exists. Once introduced, readers must reject unsupported major versions clearly and migrate compatible older versions deterministically.

## Test requirements

- Unit coverage for coordinate conversion, sizing, presets, ordering, alignment, distribution, serialization, and DPI calculations.
- Integration coverage for import-to-reopen, replace, auto-label, and PPTX export.
- Golden geometry comparison between a known project and PPTX objects.

## Known limitations

No PDF/EPS import, multi-page TIFF panel extraction, AI recognition, journal presets, cloud synchronization, collaboration, or automatic source refresh.
