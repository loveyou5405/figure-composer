# Figure Composer v1.3.1

Release date: 2026-09-22
Semantic version: `1.3.1`
Visible version: `v1.3.1`
Project schema: `0.1.0`

## Scope

This maintenance release makes project naming and saving clearer while preserving the compatibility contract for existing `.figproj` files.

## Changes

- Figure names are editable from the top bar and persist inside the project document.
- Save overwrites the current writable file when a browser or desktop file handle is available.
- New files and browser downloads use `YYYYMMDD_Custom Name.figproj`.
- The compact top bar no longer exposes a separate Save As button.
- Older supported `.figproj` files remain importable; future schema changes require explicit migrations and regression tests.

## Verification contract

- Run `npm run launcher:generate`, `npm run version:check`, `npm test`, and `npm run build`.
- Verify dated filename generation and writable-handle overwrite behavior.
- Verify legacy project import remains covered by persistence tests.
