# Figure Composer v1.5.0

Semantic version: `1.5.0`
Visible version: `v1.5.0`

Adds explicit Auto Layout groups. Selected panels can be grouped or ungrouped in the Layout sidebar. Auto Layout orders each group as one unit by its earliest non-empty label, preserves the panel-list order within a group, and does not split groups across overflow pages. Labels remain independent. The project schema stays at `0.1.0`; `layoutGroupId` is optional, so previously saved `.figproj` projects without the field remain importable.
