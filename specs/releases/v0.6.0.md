# Figure Composer 0.6.0 — Editable PPTX Export

Checkpoint: `0.6.0-m10`  
Date: 2026-09-17

## Included

- One ordered A4 PowerPoint slide per selected project page.
- All pages or current page export scope.
- Independent named picture objects for every panel.
- Independent editable text boxes for every visible label.
- Direct deterministic conversion from page-local millimeters to PowerPoint units.
- Original PNG/JPEG/SVG preview data without slide flattening; SVG retained as vector media where supported.
- Missing-source preflight and non-mutating outside-page warnings.
- Golden plan and OOXML package tests.

- Cropping, rotation, grouping, and advanced export controls.
